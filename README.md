# WEBSITE EXPERIENCE
==================================================

Build a long-form, highly polished single-page agency website.

Use smooth scrolling.

Use subtle but noticeable motion.

Use Framer Motion or another lightweight animation system.

Animations should include:
- Scroll reveal
- Text slide-ins
- Marquee
- Hover scaling
- Magnetic buttons
- Image/card tilt
- Sticker-like floating elements
- Number counters
- Horizontal scrolling sections
- Slight rotation on selected cards
- Cursor interactions where appropriate

Do NOT overanimate everything.

The website must remain fast, responsive and professional.

Mobile experience is extremely important.

Desktop:
- Wide editorial layouts
- Asymmetrical sections
- Large typography
- Large artwork
- Plenty of personality

Mobile:
- Maintain the same personality
- Do not simply stack desktop sections
- Make typography responsive
- Keep buttons large and thumb-friendly
- Preserve the funky visual identity
